# Trained model checkpoints

Place the five best model checkpoints in this directory:

- `VLPNet_seed10_best.pt`
- `VLPNet_seed20_best.pt`
- `VLPNet_seed30_best.pt`
- `VLPNet_seed40_best.pt`
- `VLPNet_seed50_best.pt`

Each file is created automatically by `train.py` when the corresponding seed is used.
